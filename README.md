# Junior Hernandez Paulino — Professional Website

Privacy-first professional website published at [junior-hernandez-paulino.github.io](https://junior-hernandez-paulino.github.io/). It presents Junior Hernandez Paulino's experience across P&amp;C actuarial work, AI model evaluation, economics, quantitative research, finance, and the NoirShield operating platform.

## Public architecture

- Static HTML and CSS with minimal JavaScript
- Unique page titles, descriptions, canonical URLs, and Open Graph metadata
- `Person` and `ProfilePage` structured data with consistent public-profile links
- Crawlable `robots.txt` and `sitemap.xml`
- Responsive navigation, accessible focus states, image alt text, and reduced-motion support
- No analytics, advertising pixels, cookies, remote fonts, or unnecessary third-party scripts

## Privacy boundary

The public site intentionally excludes street addresses, telephone numbers, family information, EINs, private financial records, exact property locations, and credential identifiers. Professional contact is routed through public profile links until a dedicated public email address is approved.

## Local preview

Serve this directory with any static HTTP server and open `index.html` through the server URL.
